Word Complexity Score

Score = (synonyms + antonyms) / definitions, based on the Free Dictionary API.

Comma separated, up to 100 words.

Using the API directly · API reference

curl -X POST localhost:3000/complexity-score \
  -H "Content-Type: application/json" \
  -d '["happy", "joyful", "sad", "angry"]'

curl localhost:3000/complexity-score/:job_id
